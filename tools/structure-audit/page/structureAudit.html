How to read this

five minutes, top to bottom

The vocabulary

Import
One file naming another in an import … from './…' line. Type-only imports count too, because they still tie the two files together in the module graph.
Area
A top-level folder of src/, split one level deeper for services/, services/engine/ and layers/. areas. Imports inside one area are ignored everywhere on this page; only imports that cross an area boundary are shown.
Tier
A group of areas that sit at the same height in the intended architecture. The rule is one sentence: a file may import from its own tier or any tier below it, never from above. Leaves sit at the bottom, UI at the top. The six tiers here are a proposal, not a fact about the code.
Against the grain
An import that breaks the rule: a lower tier importing a higher one. Two more rules apply regardless of tier: a Layer never imports a sibling Layer, and nothing but compositions/ imports a Layer.
Cycle
A set of files where every file can reach every other by following imports. Cycles make files impossible to understand or test one at a time.
Closure cell
A let inside a factory function such as createFooRenderer(). It is state, but private to one object rather than in the Redux store.

A walkthrough

  1. Start at the matrix. Each row is an importing area, each column an imported area, and a cell's shade is how many files cross that boundary. Because rows and columns share the tier order, a healthy codebase paints only the triangle above the diagonal. Every filled cell below the diagonal is an import going the wrong way, and gets a red ring. Hover a cell for the count, click it to open the file pairs.
  2. Read the three chips. They total the red rings by rule. Click one to list only those area pairs, densest first, and click any pair to see exactly which files are involved. That list is the future allow-list of the ratchet test.
  3. Argue with the tiers. Every area in the left panel has a dropdown. Move an area and the matrix, chips and list recompute. If moving services/animation up to the State tier makes its red rings disappear, that tells you where the tour machinery really belongs. When you find an arrangement where the remaining red is only things you agree are wrong, that arrangement is the answer to Q2.
  4. Check the cycles. They cannot be fixed by reordering tiers; a cycle is a knot inside one or more areas. The largest one is usually the biggest single structural finding on the page.
  5. Inventory the state. The tabs go from strongest signal to weakest. Module-level let and mutable containers are process-wide singletons and deserve a look one by one. Closure cells are the engine's legitimate runtime state; the per-area bars show where it concentrates.

What the page cannot see: shader package:: imports, string-literal paths, and anything under tools/ or tests/. It also cannot judge whether an import is right, only whether it agrees with the tiers you set.
