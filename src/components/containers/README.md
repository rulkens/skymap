# `src/components/containers/`

This directory holds every store-boundary component in the app. Each file follows the `<Name>Container` → `<Name>` pairing rule: the container is named `<Name>Container` and renders the `<Name>` presentational component (the name minus the `Container` suffix), making the pairing trivially scannable. Containers own ALL `useAppSelector` / `useAppDispatch` reach; presentational components import nothing from `store/` or `state/` and are testable with plain props, no Provider. The uniform `memo()` idiom applies: `import { memo } from 'react'`, define `function ComponentName(...)`, `export default memo(ComponentName)`. This directory is the deliberate skymap analog of repperjs's `src/state/containers/` — skymap cannot place containers there because `src/state/` is framework-agnostic by contract and containers call `useAppSelector`/`useAppDispatch`. See spec §1 (`docs/superpowers/specs/2026-06-19-react-store-containers-design.md`) for the full convention and rationale.
