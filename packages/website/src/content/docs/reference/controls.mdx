import { DOCS_CONTROLS } from '../../../data/docsControls';

export const controls = (id) => {
  const group = DOCS_CONTROLS.find((candidate) => candidate.id === id);
  return {
    cols: 'detail',
    head: [group.kind === 'keys' ? 'Key' : 'What you do', 'What it does', 'Where it applies'],
    rows: group.rows.map((row) => [
      group.kind === 'keys' ? { keys: row.input } : row.input[0],
      row.does,
      row.where,
    ]),
  };
};

## Where a control applies

The last column of each table uses these words.

- **Anywhere** is the scene, a tour, an exhibit and the welcome screen, as long as no text field has the keyboard.
- **The scene and exhibits** takes in a tour while it is paused. While a tour plays, the tour steers the camera.
- **A text field** is the search field or the date field of the clock.

## What has no control

- **Flying with the keyboard.** The keys choose a focus, and the mouse, the trackpad or a finger does the rest.
- **Auto-rotate.** It has a button in the top bar and no key.
- **Sliding the view and tilting it, on a touch screen.** Both need the right or the middle mouse button.
- **Moving from button to button with <Keys of="Tab" />.**
