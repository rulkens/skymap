<Fact id="ref-objects-rows" inline /> Put an id after `#focus=` in the app’s address to open that object; an exhibit’s id goes after `#exhibit=` and a tour’s after `#tour=`. To link to a row of this page, put the same id after the page’s address: `#body-saturn`.

The millions of galaxies and stars that come from the catalogues are not listed. The app’s search finds a GLADE or 2MRS galaxy by its designation, as [Finding things](/docs/guide/finding/) describes, and any object you have selected has an id in the address, in one of the forms on [URL parameters](/docs/reference/url-parameters/#object-ids).
