## Two kinds of work

**By the number of things.** A galaxy or a star is a few vertices that the graphics processor must transform, however small it ends up on screen. This work grows with the [data size](/docs/reference/glossary/#data-size) (the large one holds nearly nine times the galaxies of the small one: [See more or fewer galaxies](/docs/guide/settings/#see-more-or-fewer-galaxies)) and is independent of the window’s size.

**By the number of pixels.** A glow, an atmosphere or the cosmic web costs for every pixel it covers, and many glows over the same pixel cost many times. This work grows with the window and is independent of the number of galaxies loaded.

## What else keeps it down

- **Nothing, when nothing changes.** With the scene at rest the app draws no frame ([Laptops and desktops](/docs/guide/screens-and-domes/#laptops-and-desktops)).
- **Work done once.** A galaxy’s tilt, luminosity and its weight in the density correction are computed when its file arrives and stored with it. The two fixed tables of each atmosphere are made as the app starts.
- **Few [draw calls](/docs/reference/glossary/#draw-call).** A file of stars is two, one for its single stars and one for its summed boxes.
