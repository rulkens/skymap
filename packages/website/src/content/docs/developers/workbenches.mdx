## Galaxy renderer

Draws one galaxy from a set of parameters: a smooth field of starlight, a map of dust, glowing gas where stars form, and bloom over it all. A panel compares the result with eight reference galaxies, seven of them with a photograph, and can search for the parameters that match one. It is where we judge whether a generated galaxy is good enough to stand in for a real one on a close approach.

## MCPM workbench

Runs the [Monte Carlo Physarum Machine](/docs/reference/glossary/#mcpm) in the browser, on the graphics processor, over a box of real galaxies, and shows the web growing as it runs. The density field the app draws was computed elsewhere, by the authors of the <Source id="mcpm-vac">SDSS Cosmic Slime catalogue</Source>; this is a port of the simulation itself. A field made here can be saved in the app’s format and shown in the app.

<WorkbenchFigure id="mcpm" />

## Flow workbench

Loads the <Source id="cf4pp">CF4++</Source> velocity field, a grid of 128 cells a side, and lets particles drift along it, so that the places galaxies stream towards show as knots.

<WorkbenchFigure id="flow" />

## Scene workbench

Views a place rebuilt from survey data, in each form the build makes of it: the points of a laser scan, Gaussian splats trained on aerial photographs, and a textured mesh. An outline drawn here is what the mesh is cut to. The one place so far is Søndermarken, from Denmark’s <Source id="dhm">height model</Source> and <Source id="skraafoto">oblique aerial photographs</Source>. It reads files that the scene commands write on the same machine, so it is not published.

<WorkbenchFigure id="scene" />

## Named-galaxy curator

Prepares the picture of a named galaxy: you choose a source image, frame it, have the foreground stars taken out, and set how its dark sky fades to transparent. The star removal is done by StarNet2, a separate program that has to be installed. The curator writes the result into the repository, which is why it runs only from a copy of it.
