If you are preparing a lesson, [Use skymap in the classroom](/classroom/) has views that are ready to open. This page is for when you want to steer yourself. The same controls work at every scale, from a few metres above the ground to the whole map.

## A camera on a target

<Fact id="focus-meaning" />

<Fact id="one-camera" />

So moving around is three things: turning about the target, moving nearer to it or further from it, and choosing another target.

## Look around an object

| | Control |
| --- | --- |
| Mouse | Drag with the left button |
| Trackpad | Click and drag |
| Touch screen | Drag with one finger |
| Keyboard | None |

<Fact id="orbit-drag" />

The scene follows your hand, as a globe does: drag to the right and the object turns to the right.

## Move nearer or further away

| | Control |
| --- | --- |
| Mouse | Turn the wheel |
| Trackpad | Scroll with two fingers, or pinch |
| Touch screen | Pinch with two fingers |
| Keyboard | None |

<Fact id="zoom-inputs" />

One control covers every scale. Keep scrolling out from Earth and you pass the Moon’s orbit, the planets, the nearest stars, the Milky Way and the galaxies around it, without changing mode. The scale bar at the lower right tells you where you are: [Finding things](/docs/guide/finding/#what-you-are-looking-at) explains how to read it.

## Go somewhere else

| | Control |
| --- | --- |
| Mouse | Double-click the object |
| Trackpad | Double-click the object |
| Touch screen | Double-tap the object |
| Keyboard | <Keys of="/" />, type a name, <Keys of="Enter" />. Or <Keys of="F" /> for the selected object |

<Fact id="double-click-focus" />

<Fact id="focus-key" />

The Focus button on a pinned card does the same as <Keys of="F" />. Cards are described under [Info cards](/docs/guide/info-cards/).

For anything that is not on screen, use the search: [Finding things](/docs/guide/finding/) covers what it matches. A link can also name the object to open on, which is the subject of [Sharing a view](/docs/guide/sharing/).

<Fact id="focus-follows" />

That is why Jupiter stays in the middle of the screen while its moons go round it. The clock is described under [Time](/docs/guide/time/).

## Slide the view sideways

| | Control |
| --- | --- |
| Mouse | Drag with the right or the middle button |
| Trackpad | Drag with a right click held |
| Touch screen | None |
| Keyboard | None |

This moves the point the camera turns about, without turning. skymap has no free flight, and this is the nearest thing to it: the camera then turns and zooms about a point beside the object. The next double-click or search result puts it back on an object.

## Get back

| | Control |
| --- | --- |
| Mouse | The Home button in the top bar |
| Trackpad | The Home button in the top bar |
| Touch screen | The Home button in the top bar |
| Keyboard | <Keys of="H" /> or <Keys of="E" /> |

<Fact id="home-key" />

<Fact id="esc-clears" />

After <Keys of="Esc" /> the camera still turns about the same point in space, but it no longer travels with the object that was there.

## On a touch screen

A phone or a tablet has the one-finger drag, the pinch, the tap and the double-tap from the tables above.

<Fact id="touch-gestures" />

To reach a surface on a touch screen, double-tap the planet and pinch in. To look at the horizon from there you need a mouse.

## The keys

| Key | What it does |
| --- | --- |
| <Keys of="/" /> | Opens the search |
| <Keys of="F" /> | Flies to the selected object |
| <Keys of="H" /> or <Keys of="E" /> | Flies home to Earth |
| <Keys of="Esc" /> | Unpins the card and lets go of the focus |
| <Keys of="Tab" /> | Hides the interface, or shows it again |

<Fact id="hide-interface" />

While you type in the search, the letters go to the search and not to these keys. The keys for the clock and for tours are on their own pages, [Time](/docs/guide/time/) and [Tours and exhibits](/docs/guide/tours/), and every key is listed under [Controls](/docs/reference/controls/).
