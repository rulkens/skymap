## MISFITS & SURPRISES

1. ~~Generated artifacts have no home in the 3-way taxonomy: MW v1 (GPU-generated), volumes' addVolumeField (imperative upload), earthTiles (streamed virtual texture) are three distinct non-fetch shapes. Need a 4th kind ("streamed/paged"); "generated" needs the mismatch-detection pattern (runFrame.ts:211-281) promoted to a named helper.~~ RESOLVED. The 4th kind exists — baked | generated | fetched | streamed (#7), earthTiles being streamed. The named helper is superseded by #13: the mismatch compare is resource-owned (MilkyWayCloud.reconcile, RenderTargets.reconcile), so there is no helper and no walker. And addVolumeField is not a fourth shape needing a kind: #14 folds it into the one uploadVolumeField ingest path and classifies the door as an ingest-contract entry point, not an artifact kind.
2. Wake is not a registry — one hand-maintained boolean expression (shouldKeepTicking). Every self-animating subsystem beyond camera/fade/route is a named field added to the signature/body (starFadeAnimating, earthTilesAnimating, flow's bespoke clause, followApproachEaseActive).
3. Cross-subsystem ambient state via a shared GPU uniform: structureFocus → ctx.focusBlend/ctx.focus → one shared state.gpu.focusUniform bind group consumed by point-sprites, disks, pick.
4. Shared per-frame derivations recomputed at each call site, not hoisted: sceneBodyPartition, partitionStarsByResolution, atmosphereDrawList, drawableRings — computed independently inside enabled() AND draw() of every consumer. Drift risk; contrast prepareStarCut (hoisted + memoised on ctx).
5. Two ContentLayer rows sharing one mutable GPU resource (selection halo) — safe only via slab-partition invariant in prose. Contract needs "shared handle across N of my own layer rows" as first-class.
6. FOREGROUND_MAX_DISTANCE_MPC is a single constant ANDed into ~9 unrelated layers' enabled() — hard-gates the whole (foreground:0, NEAR0) step from outside any subsystem. No declarative slot for a shared cross-cutting step gate.
7. Debug-only content layers share the production registry with no distinguishing flag.
8. "New render target ⇒ new frameProgram step" is a hand-edit outside any bundle boundary (confirmed).
9. Presentation producers are three different mechanisms wearing one name: LabelProducer (formal interface, labels only); direct produce* calls (markers); ContentLayer.drawPick walked by the parallel pickProgram (with @group(0) pick-camera-prefix contract honored by convention).
10. pickEnabled wider than enabled where one layer is the sole pick site for another layer's content (planetsLayer for flat∪textured; bodyGlintsLayer/starPointsLayer for caption-only anchors like Sgr A*). A single "layers" list under-specifies pick ownership spanning rows.
11. mw-aggregate has the ONLY non-constant scale in the target table (mwAggregateDivisor threaded by name) — confirmed.
12. Focusability/selectability is a wholly separate per-kind parallel table system: ClickResolver, FocusableTarget, SelectionRow, buildFocusable, extractSelectionRow, resolvePickTable, selectionHaloTable, clickHandler, focusFraming, resolveFocusId, urlHashFor — every focusable kind hand-adds a row to ~10 files. As large a surface as "is this drawn"; the bundle contract names nothing here.
13. PASS_GROUP_TITLES is a second hand-maintained table a new target must be added to (beyond spec row + frameProgram step).

## 12-LINE SUMMARY

1. Swept all 30 CONTENT_LAYERS rows, both compute steps, full runFrame body, initGpu/engine teardown, wiring/*, watchWakeSaga, presentation/*.
2. 14 real subsystems; solar-system bodies is the largest (12 layers) and densest misfit zone.
3. Every subsystem maps onto "settings + N ContentLayer rows + GPU handles in initGpu/engine teardown" — solid skeleton to anchor the spec.
4. Liveness: only 2 deriveXLiveness files exist; inline enabled() gates (sometimes over shared derivations) dominate — permit both forms.
5. Wake: one hand-maintained boolean expression; bundle votes should fold into the anim bag, not a subscription model.
6. Presentation: three distinct mechanisms (LabelProducer / produce* calls / drawPick+pickProgram) — name the split.
7. Bodies: one shared foreground:0 target, one un-owned distance gate, 4 shared derivations recomputed per call site.
8. structureFocus is cross-subsystem ambient state via a shared focus-uniform bind group.
9. Selection halo: two rows share one mutable GPU buffer, safe only by prose invariant.
10. Artifacts need a 4th kind: "streamed" (earthTiles); fold imperative upload into "generated".
11. Focusability/selectability is a separate ~10-file-per-kind surface the contract doesn't cover — as large as the render surface.
12. Vocabulary mostly reusable as-is; don't coin "phase"; "planner"/"liveness"/"producer" each cover several divergent incumbent shapes — acknowledge, don't paper over.
