# Film Look Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the film-look post pass (grade, grain, chromatic aberration, edge softness, anamorphic bloom and streaks, veiling glare, area-aware bloom cap, letterbox) as a switchable, off-by-default production feature whose "off" frame is today's frame.

**Architecture:** The grade rides the existing tone-map draw behind a WGSL `override FILM` pipeline variant; the glow rides the bloom pyramid as three extra pass kinds gated by shared predicates; the letterbox is two DOM bars over the canvas, under the HUD. Settings are one `film` cluster; the frame hands the compositor a resolved `FilmLook | null`.

**Tech Stack:** TS, Redux Toolkit, WebGPU/WGSL via the WESL linker, Vitest, React.

**Spec:** `docs/superpowers/specs/2026-11-13-film-look-design.md` (sections cited as §N). Spike source: branch `spike/film-look`; read a spike file with `git show spike/film-look:<path>`, never check the branch out. Port shader maths from it; do not port its contracts.

## Global Constraints

- Look off = today's frame: same passes, same pipelines, same shader code, no new VRAM (§1, §8).
- No optional field that silently falls back: `ToneMap.film` is `FilmLook | null`; `fold` takes a `FoldKind`; `bright` takes `{ threshold, cap, capFloor }` (§3.2).
- Constants live in `src/data/`; types one per file under `src/@types/`; no inline types (`tests/conventions/noInlineTypes.test.ts`).
- Every `.wesl` edit: read the `wesl-shaders` skill first; imports at the top; `package::` prefix; `textureSampleLevel` inside branches.
- Uniform packing matches §5's table byte for byte; `io.wesl` mirrors it.
- Comment budget: module header ≤ 10 lines, comment lines ≤ half the code lines; no "SPIKE" markers, no history.
- Knob names: `grainSizePx`, `chromaticPx`, `softnessPx`, `cap`, `streakStrength`, `veil` (§4).

## Review Focus

Inputs the spec implies and a person will meet; each pinned to a task's test:

1. Film on while HDR is on: lanes 6–7 and 8–17 both packed, FILM variant picked (Task 4 test).
2. `streakStrength` dragged to 0 while the look is on: no streak pass encoded and no `viewOf('streak0')` throw (Task 5 test, the shared predicate).
3. The look toggled on from the Display panel after boot: rows allocate before the first streak pass (the `allocateWhen` contract; Task 5 uses the same predicate on both sides).
4. Letterbox on at a portrait or square viewport: bar height clamps at 0, nothing covers the view (Task 6, the `max(0px, …)` in the CSS; eye check at 400 wide).
5. `#film=1` on a shared link, then removing it: the look turns off via `readAbsent` (Task 7 test).

**Observable behaviours (smoke, on this worktree's port):**
- `#focus=star-sun&film=1`: the Sun's disc washes out smoothly; without `film` it is today's Sun.
- `#focus=galaxy-cluster-virgo-m87&film=1`: horizontal streaks on bright cores, grain changes every frame and never tiles.
- `#focus=body-earth&t=2026-11-12T07:00:00Z&film=1`: aberration and softness grow toward the corner; stars unchanged in brightness against the no-film shot.
- DebugPanel Letterbox on: black 2.39:1 bars over the canvas and its labels, HUD on top; a `npm run shot` carries the bars; nothing covers the view at 400 wide.
- Display → Film look toggle flips the look live; `#film=1` appears in the URL and clears when toggled off.
- Perf: look off within noise of the baseline on all six scenarios.
