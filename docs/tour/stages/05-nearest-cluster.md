## Intent

Step up from "neighbourhood" to "cluster" — the first dense knot of galaxies,
a clear jump in scale and gravity.

## Camera

Log-dolly out (~4 → ~16 Mpc), then a slow arrival orbit around the cluster
core so the density reads as a 3D swarm, not a flat patch.

## On screen

`The nearest cluster` + narration. Virgo's name auto-labels (structure
labels + markers on).

## Tweaks

- Frame so the cluster fills a good fraction of the view but the surrounding
  field is still visible — the contrast is the point.
