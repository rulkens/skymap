# Architecture weak points — 2026-10-16

Where the architecture bends today, and what breaks first when the project grows to many more datasets and features. Written against `main` at #914 (1,598 commits, 781 PRs since 2026-05-03). Three read-only passes: engine core, data pipeline, state/URL/UI. Every finding carries `file:line` evidence; a finding marked **verified** was re-checked by hand after the pass, the rest are **reported** and worth a glance before acting.

Not a backlog: items here that already have a backlog line are cross-referenced, not duplicated. Not a style review: the comment budget, one-symbol-per-file and the barrels ban are out of scope except where a break is load-bearing.

## The seven patterns

The thirty-odd findings below reduce to seven recurring shapes. Fix the shape and most of the instances fall out.

| # | Pattern | Instances | Why it bites at scale |
| --- | --- | --- | --- |
| A | **Derived in theory, hand-listed in practice.** The registry is the declared single source of truth, but a parallel hand-kept list sits beside it. | five composition lists in `src/compositions/` and `src/data/sources.ts`; `DATA_FAMILIES` regex; `URL_HASH_FOR`; `SELECTION_KINDS`; `buildAllBins` named inputs; `TOGGLEABLE_SOURCES`; `allowDataFile` | Every new source edits N places; the compile-checked ones are fine, the silent ones ship a half-wired source. |
| B | **Silent failure paths.** A miss degrades to "draws nothing" instead of throwing. | no GPU error scope; `resolvePassNames` drops unknown names; `dataUrl` identity fallback; missing build input → `[]`; non-galaxy format mismatch retried then blank; unknown URL keys dropped | Optional layers hide their own absence, so a regression is found by a user, not CI. |
| C | **One code space, four jobs.** `Source` is registry key, pick code, visibility-mask bit and `galaxyType` switch arm. | `src/data/source.ts`, `selectionEncoding.ts`, `maskWith.ts`, `galaxyType.ts` | The mask wraps at 32 and the pick field at 63; registry-only rows spend both budgets. |
| D | **Ordering by convention.** Phases, sagas and build steps communicate by mutating shared state, with the order in a comment. | boot phases; arrival vs hashchange; takeover exit; frame-context focus patch; build DAG in DATA.md | Each new Layer author rediscovers the order; the symptom is a race or a stale value, never an error. |
| E | **Core still owns Layer-shaped code.** | bodies (~9k lines), structure focus, world labels, `scaleFadeBands`, Milky Way model, closed selection unions | A new dataset with bodies, a new focusable extent, or a new label family needs core edits despite the Layer contract. |
| F | **Many writers, one ratchet.** Only the camera runtime has a single-writer test. | `updateSelectionFocus` from 9 files, `clearSelection` from 8, `pause` from 7, three clock capture/restore copies | Restores disagree; a new feature picks one of several paths. |
| G | **Contracts versioned once.** Only the galaxy `.bin` has a typed stale-format path; the URL hash, settings snapshots and nine other binary families have none. | `formatVersionError.ts`, `retryPolicy.ts`, `hashParamSources.ts`, `mergeSettingsSnapshot.ts` | Shared links and saved scenes break silently across releases. |

## Engine core

1. **Every Layer pass receives the whole core state** (pattern A, E) — _reported_. `PassState` (`src/@types/engine/frame/PassState.d.ts:12-23`) is a `Pick<EngineState>` that still includes `gpu`, `subsystems`, `assetSlots`, `data` and every Layer's `settings`; asset factories get the full `EngineState` (`SlotDeps.d.ts:30-33`, `createLayers.ts:219`). `starCatalog` and `blackHoles` draw through `state.gpu.bodyPickRenderer`; `galaxyCatalog` reads `state.gpu.focusUniform!` though `LayerCoreDeps` already hands it over. Because `PassState` depends on the settings root type, the composition cannot be read off `APP_COMPOSITION` (circular alias), which is why five parallel lists exist: `compositions/app.ts`, `appVisibility.ts`, `appSettingsSlices.ts`, `appExhibits.ts`, `data/sources.ts:15-28`. Direction: narrow `PassState` to settings, tier and selection plus explicit capabilities; hand shared renderers through `LayerCoreDeps`.

2. **A misplaced pass fails silently; there is no GPU error scope** (B) — _verified_. `grep pushErrorScope|uncapturederror src` returns nothing. `src/data/rendering/frameSections.ts` hard-codes every Layer's pass names and targets; `checkFrameOrder.ts` checks presence, duplicates, scope and target existence but not that a pass's pipeline formats match its line's target or slab (COSMO is `depth24plus`, the rest `depth32float`). A wrong slab invalidates the command buffer and the only symptom is a console warning and a black frame. `resolvePassNames.ts:8-10` drops unknown names by design; a pass listed only on a capture line passes the check but `passSlabOf.ts:16-18` skips captures, so `pickProgram.ts:305` silently makes it unpickable. Direction: a pass declares its slab and target kind, `checkFrameOrder` cross-checks against the target rows' formats, and dev builds install `device.onuncapturederror`.

3. **Bodies live in core; the `body` Layer is 227 lines of settings** (E) — _reported_. Twelve of thirty `GPU_HANDLE_ROWS` are body or atmosphere renderers; ~3.3k lines of body code in `frame/`, 4.9k in `gpu/renderers/{bodies,atmosphere}`, plus `surfaceTileSubsystem.ts` (632). `runFrame.ts:260-326` plans surface tiles inline instead of through a `FrameContentPlanner`; `deriveBodyStates.ts:29` imports `SAMPLED_BODIES` statically; `BodyRowSource = 'lens' | 'insideAtmosphere'` is a closed core union naming Layer concepts. A dataset with bodies (asteroids, exoplanet hosts) cannot arrive through a Layer. Direction: form the `body` Layer and add a contract member for contributing scene bodies or anchors.

4. **Boot is ordered by mutation** (D) — _reported_. `bootstrap.ts:1-5` says phases communicate only by mutating state; `phaseLocals?` is optional and read with `!` (`wireSlots.ts:332`, `wireInput.ts:36`); 38 GPU handles start `null`. The `pickProgram` handle row captures `state.passes` by value (`gpuHandleRegistry.ts:314`) with a stale comment naming `focusUniform` as the dependency when it is `createLayers`; moving the row captures `[]` and picking returns nothing. Layer `sourceCounts` feeds dispatch `'ready'` (`createLayers.ts:78-81`) before `wireSlots.ts:358` dispatches `'loading'`; `starCatalogSourceCounts.ts:5-11` documents the workaround. Direction: each phase returns a typed product the next phase takes; gate Layer feeds on the `loading` dispatch.

5. **Structure focus is patched into the frame context after construction** (D, E) — _reported_; backlog `2026-10-16-frame-context-mutable-focus-cluster.md`. `frameContext.ts:141-159` builds placeholders, `runFrame.ts:228-237` overwrites them after `deriveView`; `runFrame.ts:229` hard-codes `type === 'structure'`. Any earlier reader sees `ZERO_FOCUS`; a second focusable extent (void, wall) needs core edits.

6. **Selection and source kinds are closed unions in core** (A, E) — _reported_. `SELECTION_KINDS` (`data/selection/selectionKinds.ts:7-15`), `SelectionRef` arms, `FocusableTarget`, the 11-arm `SourceEntry` union, `TARGET_IDENTITY_KEY`, `URL_HASH_FOR` (which imports `layers/blackHoles` at `urlHashFor.ts:23`), `detailCardTable`, and `SettingsAction` (imports flow and galaxyCatalog slice types). A new selectable Layer touches six to eight core files. Totality makes this loud, not silent, but the Layer is not self-contained. Direction: derive the kind unions from composed `selection` rows.

7. **World labels are drawn only from inside the zoneOfAvoidance Layer** (E, B) — _reported_. `runLabel3DProducers.ts:33` uploads every Layer's `worldLabels` to core's `label3DRenderer`, whose only draw call is `zoneOfAvoidanceUpsamplePass.ts:21-24` behind ZoA's `enabled` gate. A second Layer's world labels vanish whenever ZoA is off. Direction: give the renderer its own core line, or make it ZoA's.

8. **`EngineState` is a ~90-member bag whose store getters tear mid-frame** (D) — _verified in part_: 28 top-level fields, 79 importers. `engine.ts:132-146` reads `store.getState()` live per access while `runFrame.ts:105` claims one snapshot per frame; the frame dispatches camera, scale and body-distance actions before passes run, so two passes can see different store states. `contentVersion`'s docblock says galaxy-only single writer; `createLayers.ts:76` bumps it on any Layer's count report. Direction: freeze one root state per frame into the context; split boot product, per-frame view and runtime scratch.

9. **Layers import core private helpers, core holds Layer tuning** (E) — _verified counts_: `milkyWay` and `starCatalog` each make 22 imports from `services/engine/`, 13 of milkyWay's into `galaxyGenerator/v1/*`, which the CLAUDE.md marks "to be deleted". `structure` imports `pickDepthFormat` from `frame/pickProgram`; `starCatalog` and `galaxyCatalog` import helpers with no core consumer. Reverse: `utils/star/planStarChunks.ts:15-26` imports starCatalog's private `@types`; `SCALE_FADE_BANDS` holds rows for five Layers. Direction: move single-consumer helpers into their Layers; Layer-declared fade bands.

10. **A module-level Map is a Layer-to-core side channel** (D) — _verified_. `src/services/bodies/trajectoryRegistry.ts:11-12` is a global `Map` plus version counter; the `missions` Layer writes it (`loadSpacecraftTracksSaga`, `create.ts`), core's `deriveBodyStates` reads it, `destroy()` never clears it. Fourteen more module-level `let`s hold caches (`deriveBodyStates.ts:44`, `produceSceneBodyCaptions.ts:32-51`, `dataManifest.ts:12-13`, `orientDeltas.ts:34`). A second engine instance or an HMR re-create shares them. Direction: per-engine state behind a `LayerCoreDeps` capability; reset caches in `destroy`.

11. **Layers cannot take part in the HDR swap-format rebuild** (B) — _reported_. A Layer's `GpuContext.format` is the boot format (`createLayers.ts:93`); `buildSwapRenderers.ts:153-158` rebuilds only core rows flagged `rebuildOnSwapFormat`. A Layer overlay on a `'swap'` line works until the user toggles HDR, then drops silently per item 2. Direction: an `onSwapFormat` hook, or forbid Layer passes on swap lines in `checkFrameOrder`.

12. **The pick program re-implements the render program's order and formats** (A) — _reported_. `pickProgram.ts:296-327` has its own slab fold with COSMO forced last and hand-copied depth formats at `:80-81`; it ignores the frame order's depth, slot and capture data. Direction: derive pick targets and order from the same expanded steps and `RenderTargetSpec`.

## Data pipeline

1. **The deploy allow-list is a third hand-typed spelling of every filename, and dev hides the miss** (A, B) — _reported_. `tools/deploy/r2/dataFamilies.ts:20,27,34,43,52` hard-code regexes; builders hard-code their own names (`buildMcpmVolume.ts:45-47`, `buildDustVolume.ts:39-41`, `buildStars.ts:556`); the runtime composes names from the registry. `dataUrl` falls back to the identity path when the manifest lacks a file (`dataManifest.ts:35-37`), so dev works and prod 404s. Direction: derive filename sets from `SOURCE_REGISTRY` through one path helper per family, and a test over every row × tier.

2. **`buildAllBins` is monolithic with a hard-coded merge priority** (A, D) — _verified in part_. `crossMatch.ts:174` merges `[...sdss, ...twoMrs, ...glade]` first-in-wins; the registry's `priority` is a fetch rank, not a dedup rank. Missing inputs become `[]` (`buildAllBins.ts:372-379,744-754`) and only present sources are rewritten, so a run without SDSS leaves stale `sdss-*.bin` beside a GLADE that now keeps the SDSS-footprint duplicates. The 1°×1° grid has no RA wrap: `cellKey` uses `floor(ra)` and `angularSepDeg` does raw `ra1 - ra2` (`crossMatch.ts:93,105,121`), so pairs straddling 0/360 survive, untested. REGALADE at 71.5M rows will not fit the parse-everything model. Direction: `dedupRank` and `dedupMode` on the registry row, an ordered-list `crossMatch`, hard error on a missing requested input, staged atomic outputs.

3. **Per-source behaviour sits in `if (source === X)` chains with silent defaults** (A, B) — _reported_. `buildGalaxyInfo.ts:109-188` (provenance links), `estimateLog10StellarMass.ts:106-118` (defaults NaN), `sourceClass.ts:126-133`. Reported live bug: DESI stores TARGETID in `objID` (`desiFits.ts:269`), the id encoder emits `pgc-<id>` for any non-SDSS source and `resolvePgc` searches only GLADE/2MRS, so a shared DESI link never resolves. Direction: registry fields (`objIdKind`, `catalogueLink`, `massEstimator`) and chains total over them.

4. **One code space, and the visibility mask wraps at 32** (C) — _verified_. `maskWith.ts:10` and `maskHas.ts:15` do `1 << source`; JS shifts are mod 32, so code 36 (`GcCluster`) already aliases bit 4 and the next free galaxy code 37 aliases bit 5. The 6-bit pick field (`selectionEncoding.ts:15`) is spent by registry-only rows (13 of 37 slots retired or never pickable). `packSelection` has no `localIdx < 2^26` assertion and REGALADE exceeds it. The `source.ts:8-13` docblock claims codes are persisted in `.bin`; `galaxyCatalogFormat.ts` has no source field, so the "append-only forever" cost is overstated. Direction: a string `SourceId` for registry and slot keys, a dense `pickCode` for pickable rows only, masks indexed by catalog ordinal, width assertions in a test.

5. **Stale-format handling is typed for galaxies only** (G, B) — _reported_. Ten binary families exist (DATA.md says seven); only `galaxyCatalogFormat.ts:243` throws `FormatVersionError`, which is the only type `retryPolicy.ts:31` and `installFormatVersionAlert.ts:26` recognise. The other nine throw plain `Error`, get retried twice and leave the layer blank. The octree folder is the literal `'star-catalog/v2'` while `OCTREE_VERSION` is 1 (`octreeFormat.ts:21,69`); meshes and tracks have no epoch folder; the tracks version is a duplicated literal. Direction: one `assertFormatVersion()` in every decoder and a single format table read by DATA.md, `DATA_FAMILIES` and tests.

6. **The manifest has no provenance and R2 only grows** (G) — _reported_. `DataManifest.d.ts` is a flat logical→hashed map: no generation, commit, input hashes or format versions. `dataFamilyOf.ts:20-26` matches basenames at any depth so old epoch folders keep being uploaded; `rclone copy` never deletes; SDSS input is picked by mtime (`buildAllBins.ts:580`). Direction: manifest v2 with generation, commit and per-entry format and input hashes; restrict each family to its current epoch; a prune step.

7. **The build DAG is implicit** (D, B) — _reported_; backlog `2026-08-10-buildfilaments-glade-skip.md`. `buildFilaments.ts:486-488` reads `glade.bin`/`sdss.bin` that `buildAllBins` no longer writes, warns, and ships 2MRS-only filaments. Ordering lives in DATA.md:136-158 and every npm script chains `build-data-manifest` by hand. Direction: a task table (inputs → outputs) with a runner that topo-sorts and fails on a missing declared input.

8. **Generated TS has no staleness check and splits one build across two channels** (G) — _reported_. Eight `*.generated.ts` files (3,385 lines); only `meshAssetsRoundTrip.test.ts` checks a committed file, against its own serializer. `famousStars.generated.ts` ships in the bundle via git while its twin `famous_stars_meta.json` ships via R2. Direction: a seed→rows diff test per generator; move render rows into the R2 sidecar; keep the ephemeris fits as TS.

9. **Star and octree naming is single-catalog; two star formats are live** (A) — _reported_. The generic octree container carries a star-named prefix and imports star LUT constants (`octreeFormat.ts:12-17,69`); `buildStars.ts:556` writes the literal `'stars'`. SKST v1 plus its Rust port are maintained beside v2. Direction: `octreeDataPrefix(family)`; builders take `binBaseName` from the row; retire v1.

10. **`rawDataRegistry.ts` is one 1,811-line literal** (A) — _verified_: 184 entries, 54 textures, 32 meshes. Keys stay compile-checked, but at 400 entries it is a permanent merge-conflict site. Direction: per-catalog modules composed into `RAW_DATA`.

## State, URL and UI shell

1. **The clock pushes one history entry per time action, including every scrub pointermove** (B) — _verified_. `hashParamSources.ts:198` writes `t` on every `time/*` action; `ExhibitTimelineContainer.tsx:65` dispatches `setSimDays` per pointermove; `watchHashWriteSaga.ts:119` pushes unless arrival or hash navigation armed replace. Back then steps through scrub positions. `hashHistoryIntegrity.test.ts` has no clock-stream case. Direction: replace-mode for clock-only diffs, or publish on gesture end.

2. **A link is applied by two paths with opposite ordering, and most UI entry points skip both** (D) — _reported_. Arrival applies the clock before navigating and never runs `readAbsent` (`arrivalSaga.ts:33-34`); hashchange navigates first then applies absent defaults (`watchHashReadSaga.ts:102-111`) while the takeover is still entering. The palette (`actionsForPaletteAction.ts:16-24`), `SplashContainer.tsx:31`, `TourDebugPillContainer.tsx:19` and `installRecorderHook.ts:87,128` dispatch focus/exhibit/tour directly, skipping `navigateSaga`'s "end the takeover before setting the clock" rule. Direction: one `navigate(intent, transition)` action owned by one saga, absent defaults applied inside it.

3. **Takeover exit relies on each body remembering to `take(exitTakeover)`; clip runs outside the snapshot** (D, F) — _reported_; backlog `2026-10-06-unify-clip-clock-restore.md`. `runTakeoverSaga.ts:13-22` does not race the body against exit; `navigateSaga.ts:133` waits on `takeoverEnded`, so a hold kind that forgets the take leaves Exit dead and every later hash navigation hangs. `clipBodySaga.ts:65-73` keeps its own clock restore and turns a paused live clock into `goLiveNow`, where `restoreSceneSaga.ts:73-77` gets it right. Direction: race once in `runTakeoverSaga`; wrap clip in `withSceneSnapshotSaga`.

4. **Settings merges replace whole clusters; exhibits rebuild clusters behind casts** (G) — _reported_; backlog `2026-09-29-takeover-replaces-camera-cluster.md`. `mergeSettingsSnapshot.ts:41`; `voyagerMissions.ts:51-71` rebuilds `items` under `as Record<…>` casts, hiding even required fields. No settings persist to localStorage (`persistedValues.ts:20`), so there is no migration path yet, which is also the moment to add one before there is. Direction: per-cluster patch merge, exhibits authored as actions, a lint banning the cast in exhibit data.

5. **The URL contract has one table but several codecs, no version, and lossy unknown-key handling** (A, G) — _reported_; backlog `2026-09-22-url-hash-for-vs-focus-id-encode.md`. Focus-id encoding exists in `urlHashFor.ts:25-52` and in each Layer row's `focusId.encode`; `hasDeepLink` answers by key presence while `linkIntentFrom` parses values, so `#t=junk` shows the veil then lands home; `pose` is decoded by field count alone; unknown keys are dropped on the next write; renamed exhibit or tour ids send old links home. The backlog claim that `hasDeepLink` hand-lists hash keys is stale (it derives them; only the query key `tour` is hand-listed). Direction: encode via `focusIdOf`, delete `URL_HASH_FOR`, keep unknown keys on write, an id-alias table.

6. **The store is statically bound to the app composition and to React components** (A) — _reported_. `navigateSaga.ts:40`, `watchTakeoverSaga.ts:21`, `watchKeyboardEventsSaga.ts:28` import `APP_EXHIBITS`; `combinedSettingsReducer.ts:8` imports `APP_SETTINGS_SLICES`; `APP_EXHIBITS` pulls React section components into the store graph. Core selectors read Layer fact keys by name (`state/engine/selectors.ts:94-142`); `CommandPaletteContainer.tsx:25-28` wires three Layer-specific search feeds beside the generic `layerSearch`. The engine, by contrast, gets the composition injected. Direction: inject exhibits and slices into `createAppStore`; move famous, alias and structure search onto `layerSearch`.

7. **Wake rules live in five places** (A) — _reported_. `watchWakeSaga.ts:45`, `watchSelectionWakeSaga`, `watchInputWakeSaga`, `watchPaletteWakeSaga` (exists only because `galaxyCatalogAssetRows.ts:63` reads `ui.paletteOpen`), plus the frame's own dispatches. A Layer reading a non-wake route renders late until something else wakes the loop. Direction: one declarative wake table.

8. **Selection, time and orientation have many writers** (F) — _verified counts_. `updateSelectionFocus` from 9 files (`InfoCardContainer.tsx:23` bypasses `requestFocus` and the URL pending id), `clearSelection` from 8, `pause` from 7; clock capture/restore three times; `setOrientation` snaps while `requestOrientationChange` tweens. Only the camera runtime has a ratchet (7 allowed writers). Direction: one intent action per field; extend the ratchet to `selection` and `time`.

9. **Deep-link id resolution retries on the wrong pulse for facts-only Layers** (D) — _reported_. `resolveFocusRefDeferringSaga.ts:20` retries on `engineSourceCountReported` / `engineStatusChanged` only; only galaxyCatalog and starCatalog declare `sourceCounts`. A new Layer whose decode needs loaded data but publishes only facts gets `#focus=` links that go home on cold load. Direction: add `factsReported` to the retry set.

10. **`src/store/types.ts` is an 8-type hub outside `@types/`**, and `utils/math/index.ts` plus `services/engine/index.ts` are the actual barrels the ban names. Minor, but `types.ts` has 72 importers.

## Cross-cutting

- **Tests are coupled to private structure.** 326 test files import from `services/engine/` and 90 from `services/gpu/`; `tests/` is 175k lines against ~140k of `src/`. A core refactor of the kind this document asks for pays a test-rewrite tax first. The 2026-09-15 prune is the model; it should recur per subsystem before each core move.
- **148 `?static` shader imports are invisible to `tsc`**; only `npm run build` catches a dangling one, so a renamed shader passes `typecheck` and CI's typecheck step. A test that resolves every `?static` specifier would close it.
- **Docs drift.** The add-data-source skill cites three paths that no longer exist (`src/data/sources/gaia-stars.ts`, `src/services/gpu/renderers/starCatalog`, `src/services/loading/slots/starCatalogSlot.ts`); DATA.md counts seven format families of ten; `source.ts` and `EngineState.d.ts` carry stale docblocks; the ADR table in BACKLOG lists four of twelve ADRs. With 650 design docs the drift rate is the risk, not any one miss. A link-resolution test over `docs/**/*.md` and `.claude/skills/**` is cheap.
- **CI gaps.** `format:check` is off; no visual regression or GPU smoke test runs in CI, so item 2 of the engine list (silent black frame) has no automated catch at all.
- **One author.** 1,580 of 1,598 commits are one person. The docs make that survivable; the implicit orderings in pattern D do not.

## What is solid

- Composition fails loudly at boot: `createLayers` rejects duplicate passes, computes, planners, asset keys and slab rows; `checkFrameOrder` runs over every view rig.
- GPU handle lifecycle: compile-time totality on `GPU_HANDLE_ROWS`, reverse-order teardown, the `_EnforceDestroyable` guard, Layer sagas cancelled before core is torn down.
- Fades are core-owned and declarative; Layers cannot drive one.
- Every binary family has a writer→reader round-trip test; content-hashed files with the manifest uploaded last make a half-synced R2 invisible; `collectDataFiles` throws on a stale local manifest.
- The galaxy tier path (`tierTargets` + `tierFilenameForSource`) is the template the other families should copy.
- `HASH_PARAM_SOURCES` with compare-and-skip and push/replace arming, locked by `hashHistoryIntegrity.test.ts`.
- No `react-redux` outside `src/store`; sagas reach the engine only through injected closures; the settings root is composed from Layer slices and stays serializable.
- The attribution gate ties every raw key and upstream host to an ATTRIBUTIONS entry.

## Early decisions that have outgrown the project

Dated from `git log --diff-filter=A`. Each was right for what it was sized for; the column that matters is what it carries now.

| Decision | Decided | Sized for | Carries now | Better shape at today's size |
| --- | --- | --- | --- | --- |
| Numeric `Source` byte as the one identity | 2026-05-03 | 3 catalogs, 1 byte | 37 codes doing registry key, pick code, mask bit and switch arm; mask wraps at 32 | String `SourceId`; a dense per-use code (pick, mask) minted from the composed registry |
| Packed 6+26-bit pick identity | 2026-05-11 | SDSS at 500k rows | 67M-per-source cap (REGALADE is 71.5M), 6-bit field spent by non-pickable rows, no width assertion | Pick carries `(layerOrdinal, localIdx)` with the width owned by the Layer's `selection` row; assert at pack time |
| Whole-file tier variants (`small` / `medium` / `large`) | 2026-05-05 | One point cloud, three device classes | `Tier` has 34 consumers and doubles as data budget and device class; SDSS large is capped at 500k "so every perf number holds"; stars already left for a chunked octree with per-source budgets (2026-10-11); galaxy octree streaming is in research | Spatial chunking per family with per-Layer budgets; `Tier` shrinks to a device-class hint |
| In-memory cross-match of three catalogs | 2026-05-03 | 3 all-sky inputs that fit in RAM | Hard-coded `[sdss, 2mrs, glade]` rank, patch and bypass modes in code, no RA wrap, 16 GB heaps for stars | Streaming per-source parse, HEALPix-keyed dedup with `dedupRank` / `dedupMode` on the registry row, staged atomic outputs |

| Shaders outside Layers, one WESL package root | 2026-05-07 | One shader folder | 29 shader families, 148 `?static` imports invisible to `tsc`, the one standing exception to Layer self-containment | Per-Layer package roots if the linker allows it; otherwise a resolver test over every `?static` specifier so `typecheck` catches a rename |

| Tests mirror `src` file by file | 2026-05 | A small tree | 326 test files import engine internals; 175k test lines against ~140k of `src`; every core move pays a rewrite tax first | Mirror Layers and `utils/`; test core through its contracts (boot product, frame program, store) rather than per file. `testing.md` already states the philosophy; the mirror rule is what contradicts it |

**Held up well.** The Layer contract (2026-09), content-hashed data with the manifest uploaded last, the floating origin (ADR 0010), core-owned fades (ADR 0001), the RTK slice composition, and redux-saga as the effects vehicle (ADR 0008). The saga layer is not outdated, it is under-applied: ADR 0007's intent-centric principle stops at the camera, which is the only field with a single-writer ratchet.

## Order of attack

Smallest change that removes the most instances of a pattern first.

1. **Split `Source` into `SourceId` + dense `pickCode`, index masks by ordinal, assert widths** (C). One PR; unblocks every new survey and removes a live aliasing hazard.
2. **GPU error scope in dev plus format cross-check in `checkFrameOrder`** (B). Turns the worst silent failure into a boot error.
3. **Registry-derived filenames and a row × tier test; `assertFormatVersion()` in every decoder** (A, G). Makes "add a dataset" a one-row edit for the two families that are not yet, and gives every family the galaxy format's stale-client path.
4. **One `navigate` action, race-on-exit in `runTakeoverSaga`, clip inside the snapshot, clock in replace mode** (D, F). Four small saga PRs that remove three duplicated restores and a history flood.
5. **Narrow `PassState`; hand shared renderers through `LayerCoreDeps`** (A, E). Breaks the circular alias and lets the five composition lists collapse to one.
6. **Form the `body` Layer and a scene-bodies contract member** (E). The largest move; do it after 5, when the contract can carry it.
7. **Manifest v2 with provenance, build task table, generated-TS diff tests** (G, D). Pipeline hygiene for the dozens-of-datasets phase.
